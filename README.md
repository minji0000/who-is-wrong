# ⚖️ Who Is Wrong? (누가 잘못했지?)

> 세상 모든 갈등과 뜬금없는 사연의 시시비비를 가려주는 유쾌한 AI 판정사 챗봇 서비스 💖

---

## 🛠️ Tech Stack (기술 스택)

- **Backend:** Java 17, Spring Boot, Spring AI (Gemini / OpenAI API)
- **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
- **Build Tool:** Gradle
- **Deployment:** Docker, Render

---

## ✨ Key Features (주요 기능)

1. **시시비비 판정사 AI**
    - 사용자가 입력한 갈등 상황이나 사연을 분석하여 누가 잘못했는지 냉철하고 유쾌하게 판정해 줍니다.
2. **센스 있는 예외 처리 (System Prompt)**
    - "대한민국 수도가 어디야?" 같은 뜬금없는 질문이나 상식 질문이 들어오면,
   진지하게 답하지 않고 판정사 콘셉트에 맞춰 **"으응? 그거는 누구와의 잘못도 아니야. 너 맞게 입력한 거 맞아?"**라며 유쾌하게 튕겨냅니다.
3. **러블리한 핑크빛 UI**
    - 부드러운 그라데이션 배경과 직관적인 입력 폼, 로딩 애니메이션을 적용하여 사용자 경험을 높였습니다.
